# SemiFin dashboard: Power BI build guide (Phase 7)

The CSVs in `dashboard/exports/` are generated by the Phase 7 section of `notebooks/06_figures_and_exports.ipynb` (`src/exports.py`). Every number is copied from the Phase 2-5 tables, so the dashboard shows the same values as the report. Rerun that section if any earlier phase changes.

**Software:** Power BI Desktop (free, Microsoft Store). Nothing else is needed. You can skip the sign-in prompt, because it is only needed to publish online.

**Save the file as** `dashboard/SemiFin.pbix`.

---

## 1. Files

| File | One row per | Use |
| --- | --- | --- |
| `dim_company.csv` | company (CIK) | Company selector, case-company flag, colour, sort order |
| `dim_year.csv` | label year 2015-2025 | Year slicer and the x-axis of every trend chart |
| `dim_company_year.csv` | company-year | Revenue group toggle (operating / low revenue) |
| `fact_ratios.csv` | company-year | 14 ratios, key statement values, flags, ROA bins |
| `fact_ratios_long.csv` | company-year-ratio | One line chart with a ratio selector |
| `fact_pnl.csv` | case company-year | Profit and loss summary (4 case companies only) |
| `fact_zscore.csv` | company-year | X1-X5, Z', zone, same-year distressed label |
| `fact_predictions.csv` | company-year scored | Walk-forward random-forest probability and risk band |
| `model_metrics.csv` / `model_metrics_long.csv` | model x dataset (x metric) | Model comparison |
| `feature_importance.csv` | feature | Random-forest SHAP importance |
| `sector_by_year.csv` | scope x year | **Do not chart.** Expected card values for checking (section 6) |

Notes on the data:

- Money values are in USD millions. Ratios and margins are decimals (0.25 = 25%).
- A blank means the value is not available. For example, a ratio is blank when its denominator is zero or negative, and the reason is in the flag columns. Power BI ignores blanks in MEDIAN and AVERAGE, which is what we want. Never replace them with 0.
- In `fact_predictions`, the row for **feature year t** uses year-t ratios to give the probability of distress (Z' < 1.23) in **target year t+1**. The model is trained only on years before t. Companies with revenue below USD 10m were excluded from modelling, so they have no prediction.

## 2. Import and data types

1. **Home > Get data > Text/CSV**, then load each file (all except `sector_by_year.csv`). Click **Load**, not Transform.
2. **View > Themes > Browse for themes**, then pick `dashboard/semifin_theme.json`. This applies the report colours (Nvidia green, AMD red, Intel blue, Wolfspeed amber).
3. In **Table view**, check these types (Column tools ribbon):
   - `cik`, `label_year`, `feature_year`, `target_year`: **Whole number**. Set **Summarization: Don't summarize** and turn the thousands separator off, so years show as 2025, not 2,025.
   - `cik_year`, `company`, `risk_band`, `ratio`, `roa_bin`, `revenue_group`: **Text**.
   - `fiscal_year_end`: **Date**.
   - Percent columns: set **Format: Percentage** with 1 decimal for gross_margin, operating_margin, net_margin, roa, roe, debt_ratio, revenue_growth, net_income_growth, prob_distress_next_year and shap_share. In model_metrics, show precision, recall, f1, roc_auc and pr_auc with 3 decimals.
4. **Sort orders** (select the column, then Column tools > Sort by column):
   - `dim_company[company]` by `sort_order`, so the case companies are listed first in report order.
   - `fact_ratios_long[ratio]` by `ratio_order`.
   - `fact_predictions[risk_band]` by `risk_band_order`.
   - `model_metrics_long[model]` by `model_order`.

## 3. Relationships (Model view)

First delete any relationships Power BI created automatically: it often links fact tables to each other on `cik_year`, which is wrong. To stop it doing this again, go to **File > Options > Current file > Data load** and untick "Autodetect new relationships".

Create these relationships. Every one is **one-to-many** with **single** cross-filter direction:

| From (one side) | To (many side) |
| --- | --- |
| `dim_company[cik]` | `dim_company_year[cik]` |
| `dim_year[label_year]` | `dim_company_year[label_year]` |
| `dim_company_year[cik_year]` | `fact_ratios[cik_year]` |
| `dim_company_year[cik_year]` | `fact_ratios_long[cik_year]` |
| `dim_company_year[cik_year]` | `fact_zscore[cik_year]` |
| `dim_company_year[cik_year]` | `fact_pnl[cik_year]` |
| `dim_company_year[cik_year]` | `fact_predictions[cik_year]` |

This layout is a snowflake. The company, year and revenue-group filters all pass through `dim_company_year` to every fact table, so one slicer filters every chart and there is only one path between any two tables.

`model_metrics`, `model_metrics_long` and `feature_importance` stay **unrelated**: they describe the models, not company-years.

In charts, always take the year from `dim_year[label_year]` and the company from `dim_company[company]`, never from a fact table. Otherwise the slicers will not line up.

## 4. Measures

Click **Home > Enter data**, create an empty table named `_Measures`, then add these measures with **New measure**. Each line is one measure.

```DAX
Companies = DISTINCTCOUNT ( fact_ratios[cik] )

Pct distressed =
DIVIDE ( SUM ( fact_zscore[distressed] ), COUNT ( fact_zscore[distressed] ) )
-- COUNT skips blanks, so company-years without a Z' score are left out (matches the report)

Median current ratio = MEDIAN ( fact_ratios[current_ratio] )
Median net margin    = MEDIAN ( fact_ratios[net_margin] )
Median ROA           = MEDIAN ( fact_ratios[roa] )

Loss-making companies =
CALCULATE ( DISTINCTCOUNT ( fact_ratios[cik] ), fact_ratios[net_income] < 0 )

Company-years = COUNTROWS ( fact_ratios )

Ratio value = AVERAGE ( fact_ratios_long[value] )
-- one row per company, year and ratio, so the average is the value itself

Z score = AVERAGE ( fact_zscore[z_prime] )

Distress probability = AVERAGE ( fact_predictions[prob_distress_next_year] )

Latest feature year = MAX ( fact_predictions[feature_year] )

Latest risk probability =
VAR y = MAX ( fact_predictions[feature_year] )
RETURN CALCULATE ( AVERAGE ( fact_predictions[prob_distress_next_year] ), fact_predictions[feature_year] = y )

Latest risk band =
VAR y = MAX ( fact_predictions[feature_year] )
RETURN CALCULATE ( SELECTEDVALUE ( fact_predictions[risk_band], "No prediction" ), fact_predictions[feature_year] = y )

Latest risk label =
IF ( ISBLANK ( [Latest feature year] ), "No prediction (not modelled)",
     [Latest risk band] & " risk for " & ( [Latest feature year] + 1 ) )

Risk colour =
SWITCH ( [Latest risk band], "High", "#C62828", "Medium", "#F9A825", "Low", "#2E7D32", "#898781" )
```

Format `Pct distressed`, `Median net margin`, `Median ROA`, `Distress probability` and `Latest risk probability` as Percentage with 1 decimal. Format `Median current ratio` and `Z score` as decimals with 2 places.

## 5. Pages

Use these defaults on every page:
- Use **one colour per company** throughout. The theme sets it, so check each legend shows Nvidia green, AMD red, Intel blue and Wolfspeed amber. If one is wrong, fix it under Format > Lines > Colors.
- Set the year x-axis to **Type: Categorical**.
- Give every chart a title that says what it shows and the units, e.g. "Revenue, USD millions (log scale)".
- **Never use dual axes.** If two measures don't share a unit, put them in two separate charts.

### Risk bands (state these on pages 2 and 4)

Put this in a text box: **Low** below 25% (green #2E7D32). **Medium** 25% to 49.4% (amber #F9A825). **High** 49.4% and above (red #C62828), which is the random forest's decision threshold, so High = predicted distressed. **Grey** = no prediction.
